# Public skills

- `writing-python`: Python tooling and script conventions.
- `report-writing`: reproducible Markdown, Python, Make, and PDF report directories.
- `type-relationship-diagrams`: D2/ELK type tables, callable notation, and SVG crossing checks.

Reusable OpenCode skills live in directories containing `SKILL.md`. `report-writing/template/` contains a report directory with `data/` for experiment scripts and headered CSVs, `paper/src/` for manuscript and figure source, and `paper/out/` for built figures and PDF. Configure OpenCode's `skills` array to point at this checkout to make the skill available from any project.
